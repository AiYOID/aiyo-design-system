# Delivery Gate 002: AiYO Design System v2 di atas HeroUI v3 (2026-10-20)

Mode: **during** (session override, dipilih pemilik di awal sesi). Pekerjaan: merombak design system dari Radix UI + komponen gaya shadcn ke HeroUI v3.2.6, font Geist, dengan warna dan branding AiYO.

**Design Read:** Reading this as: situs dokumentasi dan referensi komponen design system untuk engineer produk AiYO dan AI agent mereka, dalam gaya AiYO "Minimalist Modern" di atas HeroUI v3, dial ENERGY 2 / RHYTHM 2 / MOTION 2. Dial diambil langsung dari baris `Dial:` di DESIGN.md sebelum membangun (core Part 3, langkah 1); kalimat Design Read ini ditulis saat laporan.

## Keputusan pemilik di sesi ini

- Komponen: HeroUI v3 dipakai langsung dari `@heroui/react` (tanpa wrapper). Blok khas AiYO di `src/components/aiyo/*`.
- Gaya komponen mengikuti default HeroUI; warna, branding, dan varian warna tetap AiYO.
- Font: Geist untuk semua (Geist Sans + Geist Mono), menggantikan Calistoga, Inter, JetBrains Mono.
- Aturan dan catatan di file .md boleh diubah.

Semua tercatat di DESIGN.md §14.2.
